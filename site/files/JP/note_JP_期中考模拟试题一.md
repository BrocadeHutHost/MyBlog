### 六、编程题（参考实现要点）

**1.标签化 break 查找负数**
```java
int[][] arr = {{1, 2}, {3, -4}, {5, 6}};
boolean found = false;
outer:
for (int i = 0; i < arr.length; i++) {
    for (int j = 0; j < arr[i].length; j++) {
        if (arr[i][j] < 0) {
            System.out.println("负数位置: [" + i + "][" + j + "]");
            found = true;
            break outer;
        }
    }
}
if (!found) System.out.println("未找到");
```

**2.复合赋值与窄化**
要点：`s = s + 1` 编译错误，因为右边提升为 `int`；`s += 1` 通过编译，`s` 为 2；`(byte)300` 为 44。注释中写明“复合赋值隐含强制转换”。

**3.静态绑定与多态判断**
`Base` 的 `private f()` 和 `static g()` 静态绑定；普通实例 `h()` 在子类重写后动态绑定。通过父类引用的公共方法间接调用 `private f()` 时，仍执行父类的 `f()`。

**4.匿名内部类 + effectively final**
`prefix` 在初始化后不再修改，满足 `effectively final`，匿名内部类可以访问。若在匿名类之后修改 `prefix`，编译错误。

**5.finally 中的 return 覆盖**
`testFinally()` 返回 2，因为 `finally` 中的 `return` 覆盖了 `try` 中的 `return`。第二个方法中 `finally` 只修改 `x` 不 `return`，返回值仍是 `try` 中暂存的 1。

**6.字符串常量池与 `intern()`**
`"ab" + "c"` 编译期优化为 `"abc"`，与字面量同一对象；`s1 + s2` 运行时生成新对象；`new String("abc").intern()` 返回常量池中的 `"abc"`。

**7.自定义异常 + 接口 + 多态**
`Band.perform()` 遍历 `Playable[]`，动态绑定到 `Piano.play()` 或 `Guitar.play()`；`members == null || members.length == 0` 时 `throw new EmptyBandException(...)`。

**8.内部类综合**
创建成员内部类对象的语法：`Outer outer = new Outer(); Outer.Inner inner = outer.new Inner();`。`StaticInner` 不能直接访问 `num`，只能通过外部类实例访问或只输出独立消息。
