使用指南

顶部是栏目，左边是本页的目录，点一下就跳过去。

  • 目录是按当前页面的小标题生成的，换页会跟着换。
  • 正文里标着「待补充」的，是还没写完的部分。
  • 文章按年份归档，也可以从分类或标签进去。

制作方法

手写的静态页面，没有框架也没有构建。每篇文章是一个 HTML 文件，文章清单在 assets/posts.js，左侧目录由脚本从正文标题生成。

发布交给 GitHub Actions：推到 main，site/ 目录就发到 Pages 上。
