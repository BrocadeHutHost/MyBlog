关于本站

使用指南

点击顶部导航栏切换栏目，点击左侧目录跳转到本页的不同小节。

  • 左侧目录是按当前页面的小标题自动生成的，换页会一起刷新。
  • 正文里标着「待补充」的部分是还没写完的内容。
  • 文章按年份归档，也可以从分类或标签进入。

制作方法

站点是纯静态的：手写 HTML、一个 CSS、一点点 JavaScript，没有构建步骤，也没有框架和运行时。

  • 内容：每篇文章一个 HTML 文件，文章清单全部记在 assets/posts.js。
  • 目录：页面加载时用几行 JS 从正文的 h2 / h3 生成左侧两级目录，不需要手工维护。
  • 部署：推送到 GitHub 的 main 分支后，由 GitHub Actions 把 site/ 目录发布到 GitHub Pages。
